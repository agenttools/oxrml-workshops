# The prompt that created this editor

The editor in this folder came from one prompt, given in a session that had already made the diagrams:

> Please create a single HTML tool where I could manually make diagrams like this — maybe seed it with one of the workflows, and then I should be able to move and adjust the settings and text and add more nodes.

That is the full prompt. Claude wrote the tool in one file, seeded it with the citation-auditor workflow, and added export to PNG, SVG, and JSON.

The lesson: when a tool does not exist, ask for it. Describe the seed data, the actions you want, and the output you need. One clear sentence for each.
