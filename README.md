# oxrml-workshops

Materials for the OxRML workshops on agentic tools for ML research.

This repository uses ASD-STE100 Simplified Technical English where possible. The rules: short sentences, active voice, one instruction per sentence.

## Workshops

| # | Topic | Contents |
|---|-------|----------|
| 01 | [Dynamic workflows](workshops/01-dynamic-workflows/) | Prompt sheet, pattern diagrams, a diagram editor, and a diagram skill |

## How to use this repository

1. Open the folder for your workshop.
2. Read its README. It tells you what each file does.
3. Try the prompts in your own Claude Code session.
